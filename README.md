# CIV_4_Bot

**An autonomous, goal-driven AI player for Civilization IV: Beyond the Sword.**

CIV_4_Bot is an open-source Python desktop application designed to automate gameplay in Civilization IV. Players define objectives for their civilization, and the AI determines the strategies, tasks, and actions necessary to achieve those objectives.

Instead of manually controlling every city, unit, and diplomatic interaction, players become the strategists behind an autonomous civilization.

The goal is to create an AI capable of managing an entire civilization, adapting to changing game conditions, and competing against Civilization IV's built-in AI opponents.
